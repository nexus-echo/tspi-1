## 2. Introduction — From multiple diagnoses to one network disorder
This patient carries several "separate" diagnoses — fibroid, hypertension, systemic inflammation,
early dysglycemia, iron-deficiency anemia, a hyperthyroid-pattern, and immune hypersensitivity.
Managed in silos they would generate polypharmacy and recurrence. TSPI reframes them as one
**network disease**: interconnected nodes failing together because shared upstream systems
(microbiome, nutrient sensing, inflammation) have drifted from balance. The clinical question
shifts from *"what is each disease?"* to *"which biological axes are dysregulated, and how do
they drive these manifestations?"*

---

## 3. Clinical overview (system-by-system)
- **Structural — fibroid:** estrogen-sensitive smooth-muscle/ECM tumour; post-menopausal
  stress-triggered bleeding signals persistent hormonal/vascular instability.
- **Inflammatory — CRP 21.57:** a central pathological hub (IL-6/TNF-α/NF-κB).
- **Cardiovascular — hypertension + hs-CRP 20.21:** endothelial dysfunction + sympathetic drive;
  borderline atherogenic lipids add vascular load.
- **Metabolic — HbA1c 6.5%:** insulin resistance; insulin as a growth factor (PI3K/AKT, mTOR)
  feeds proliferation.
- **Hematologic — Hb 10.8 / MCV 67.2 / transferrin sat 12%:** microcytic hypochromic
  iron-deficiency anemia, amplified by inflammation (hepcidin).
- **Endocrine — TSH 0.416 / FT3 5.20:** relative thyroid overactivation, read as secondary to
  stress/inflammation; plus estrogen dysregulation.
- **Immune — IgE elevated:** Th2-skew / barrier dysfunction / loss of tolerance.
- **Metabolic-immune — Vitamin D 27.6:** insufficiency weakening immune & metabolic regulation.
- **Neurological — sympathetic dominance:** stress-reactive symptoms, hypertension, poor recovery.

## 4. Network disease — the unifying mechanism
**Root-cause chain (upstream → downstream):**
`Vegetarian low-diversity diet + chronic stress → microbiome dysbiosis (A17) → gut-barrier
breakdown (A18) → LPS translocation → chronic inflammation (A1, CRP 21.57) → {insulin resistance
(A5), endothelial dysfunction/HTN (A20/A23), estrogen dysregulation (A31), hepcidin-driven anemia
(A26), thyroid/autonomic destabilisation (A33/A34)} → fibroid growth + abnormal bleeding
(A25/A21).`

**Upstream hub:** microbiome/nutrient-sensing + inflammation; oxidative stress (A9) forms a
self-reinforcing loop with it. Single-target therapy fails here — **network pharmacology** (one
module → many axes) is required.
